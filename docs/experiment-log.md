`traces/manifest.csv` 自动记录设备、场景与统计量；本文件用于补充人工观察，便于后续解释异常区段。

|---|---|---|---|---|---|---|
| | | | | | | |

填写说明：

- 断连时刻：`outage_far` 类 trace 中走出覆盖范围的大致秒数；
- 人员走动区间：`person_3m` 类 trace 中人员经过的时间段；
- 环境变化：开关门、搬动设备、其他无线设备开启等；
- 备注：任何可能影响链路但未体现在字段中的因素。
