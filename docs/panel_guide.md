# 可视化面板使用指南

> 三个页签：**采集回放 → 模型评估 → 数据总览**。所有曲线都从本机 `traces/` 和 `ml/artifacts/` 现算，**没有手工补数**。
> 截图：见 [`docs/images/panel_replay.png`](images/panel_replay.png)（合成演示数据）。

---

## 一、启动（10 秒）

```powershell
cd D:\projects\PatroLink
pip install -r requirements.txt          # 含 streamlit / plotly
streamlit run panel\app.py
# 浏览器会自动打开 http://localhost:8501
```

停止：在终端按 `Ctrl+C`。
换端口：`streamlit run panel\app.py --server.port 8502`。

> 数据还没采时，面板会**自动使用 `traces/demo/` 的合成演示数据**，并在页面顶部黄色提示"这是演示数据"。真实数据放进 `traces/` 后自动切换。

## 二、每个页签看什么

### 🎬 采集回放（演示时停留最久的一页）

| 元素 | 含义 | 演示时怎么说 |
|---|---|---|
| 顶部 5 个指标 | 时长 / 收包率 / RTT 中位 / P95 / RSSI 中位 | "同一条链路，10 秒内读出它的基本画像" |
| 橙色背景 | **真实恶化区间**（RTT 平滑值超阈值，或丢包率超阈值） | "这些时间段是真变差了" |
| 深蓝线 | RTT 2 s 均值；灰虚线是阈值 | "恶化前 RTT 先抬" |
| **橙线** | 模型预测的 P(恶化)，右轴 | "预测概率在背景之前抬头 → 提前预警" |
| 下方两张图 | RSSI、丢包率 | "RSSI 先掉、丢包最后才来——这是可用的前兆链" |
| 提前量中位 | 每个恶化区间被提前多少秒发现 | "中位 3.6 s"（演示数据；真实数据看实测） |

对比演示：切到 `good_desk`（全程平稳、几乎没有橙色区间）与 `wall_5m`（台阶抬升）→ 一句话说清"位置真的影响链路"。

### 📈 模型评估

- **模型 vs 基线表**：`persistence` / `rule` / `logreg` / `hgb` 的 AUC、F1、Recall；
- **柱状图**：一眼看谁高；
- **静默 trace 误报率**：良好链路上每分钟误报几次（调度最怕这个）；
- **提前量** / **ROC-PR 图** / **预测概率 vs 真实恶化** 大图。

演示口径："训练模型在同样召回下把误报从 1.5 次/分钟压到 0（演示数据），所以不是拍脑袋调阈值。"

### 🗂 数据总览

- `manifest.csv` 记账表（每条 trace 的距离/遮挡/信道/注入参数/收包/丢包/RTT/RSSI）；
- 场景覆盖统计；**如果"全程良好"的 trace 少于 2 条会警告**（模型误报会估不准）；
- 数据规模估算（条数、总时长、滑窗样本数）。

### ❓ 使用说明

3 分钟演示脚本 + 这个面板与最终系统的关系。

## 三、数据从哪来（面板读什么）

| 面板元素 | 数据源 |
|---|---|
| 采集回放的曲线 | `traces/*.csv`（探针输出，必须有 `wall_ms, rtt_ms, rssi_dbm, lost` 四列） |
| 场景说明 | 同名 `.json` 里的 `dataset` 段（距离/遮挡/信道/热点） |
| 预测概率 | `ml/artifacts/<某次训练>/model.joblib`（侧边栏选择） |
| 模型评估 | 同目录 `metrics.json` + `roc_pr.png` + `timeseries.png` |
| 记账表 | `traces/manifest.csv` |

没有模型时：采集回放仍显示曲线和"真实恶化"背景，只是没有橙线（预测概率）——这也是一张能用的图。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面空白/一直转圈 | 服务没起或端口占用 | 看终端报错；换 `--server.port 8502` |
| 显示"合成演示数据" | `traces/` 里还没有 `probe_*.csv` | 正常；先去采集 |
| 选不到模型 | `ml/artifacts/` 下没有 `model.joblib` | 先跑 `ml/train_predictor.py` |
| 预测曲线不显示 | 模型 bundle 与数据的窗口参数不一致 | 用同一套 `--window/--horizon/--step` 重新训练 |
| 侧边栏改了目录没生效 | Streamlit 缓存 | 点侧边栏"🔄 刷新缓存" |
| 提前量显示 "—" | 该 trace 没有"提前被预测到"的事件 | 正常（模型没提前发现，或没有恶化事件） |
| 面板让你装包 | 缺 streamlit/plotly | `pip install -r requirements.txt` |
